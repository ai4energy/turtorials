# 收工沉淀铁律：让智能体自动写 `.md` 小结的黄金提示词模板

> 当智能体（Claude Code / OpenCode / OpenClaw）刚刚帮你在终端里配好环境或修完 Bug，别急着关掉会话！顺手发送下面这段提示词，就能把一次性劳动变成团队永久可复用的知识资产。

---

## 一键复制提示词

```text
刚才这项任务我们已经跑通并通过测试。请不要只停留在聊天记录里，帮我在 docs/ 目录下新建（或更新）一份中文 Markdown 小结文件：
1. 【任务背景与目标】：用两句话说明配好了什么环境/解决了什么问题；
2. 【实际执行的完整命令】：按顺序列出可复制重跑的关键命令（所有密钥与个人 IP 请务必用 <YOUR_API_KEY> / <SERVER_IP> 脱敏）；
3. 【验收结果与证据】：贴出最后实际测试命令的关键输出；
4. 【这次遇到的坑与避坑法则】：记录报错原因、如何绕开，避免下次再踩；
5. 【同步更新规则】：如果其中某条避坑适合全项目长期遵守，请顺手精简补入根目录的 CLAUDE.md 或 AGENTS.md。
```
