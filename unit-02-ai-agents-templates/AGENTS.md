# 项目智能体通用规范 (`AGENTS.md`)

> 适用于 OpenCode / Codex / 多智能体协同的标准入口文件。

## 原则一：元能力闭环（干活 + 验收 + 沉淀）
- 不要只停留在一问一答的聊天窗口；把明确的任务目标交给智能体执行，确认真实测试命令通过后，**最后一步固定要求智能体把经验写成可复用的 Markdown 文档**。
- 新接手任何仓库时，先阅读本文件与 `docs/` 下的历史 `.md` 踩坑记录，避免重复踩同一个坑。

## 原则二：安全与脱敏边界
- 读取 `~/.claude/` 或 `~/.config/opencode/opencode.jsonc` 时，只引用模型端点配置结构，**绝不打印、复制或提交任何 `sk-` 开头的真实 Key 或私人 IP**。
- 执行高危删除/覆盖命令前，必须先检查目标路径或保留备份。

## 原则三：跨端兼容与环境规范
- 脚本文件统一采用 UTF-8 无 BOM 编码与 `LF` 换行符。
- 中文文档面向工程新同学：先用一句人话讲清模块目的，再给可复制粘贴的完整命令与预期输出。
